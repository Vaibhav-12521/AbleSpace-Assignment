# Pyramid Web

Next.js (App Router) frontend for the Pyramid task manager. See the
[root README](../../README.md) for the design-token derivation, documented
deviations from the Figma, and setup.

```bash
npm install
cp .env.example .env.local   # NEXT_PUBLIC_API_URL=http://localhost:3001
npm run dev                  # http://localhost:3000
```

The API must be running for guest login to work.
